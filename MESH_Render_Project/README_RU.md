# MESH 3D Orders — Render

Проект включает сайт MESH и сервер API/Telegram-бота в одном Render Web Service.
Токен бота не хранится в HTML и не публикуется в репозитории.

## Что уже работает
- Сайт открывается по адресу Render.
- Форма заказа отправляет данные напрямую на `/api/orders`.
- Сервер сохраняет заказ в SQLite на постоянном диске Render.
- Бот пересылает заказ в настроенный администраторский чат.
- Если клиент указал ссылку MakerWorld/Printables, в Telegram есть кнопка её открыть.
- Если ссылки нет, бот добавляет кнопки поиска модели на обоих сайтах.
- Есть базовый антиспам (honeypot + ограничение частоты запросов).

## Развёртывание
1. Создайте GitHub-репозиторий и загрузите в него все файлы этой папки.
2. Откройте https://render.com/ и войдите через GitHub.
3. Нажмите **New + → Blueprint** и выберите репозиторий с `render.yaml`.
4. Render создаст Web Service. При запросе значений добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен из BotFather (никому его не отправляйте).
   - `ADMIN_CHAT_ID` — пока можно оставить пустым только если Render разрешает; иначе сначала укажите временное значение, затем замените.
   - `PUBLIC_SITE_URL` — адрес сайта Render после первого запуска (можно добавить позже).
5. После запуска откройте адрес `https://ИМЯ-СЕРВИСА.onrender.com/`.
6. В Telegram откройте https://t.me/MESH_3D_Orders_bot и нажмите **Start**.
7. Бот покажет числовой ID чата. В Render → ваш сервис → Environment добавьте/обновите `ADMIN_CHAT_ID` этим числом и нажмите Save, чтобы сервис перезапустился.
8. Проверьте `https://ИМЯ-СЕРВИСА.onrender.com/health` — должны быть `telegram_configured: true` и `admin_configured: true`.
9. Сделайте тестовый заказ на сайте.

## Важно о стоимости и постоянной работе
В `render.yaml` указан платный план Render Starter и подключён постоянный диск, потому что бот должен работать без засыпания, а заказы должны сохраняться после перезапусков. По документации Render бесплатные сервисы засыпают после 15 минут без входящих запросов, не поддерживают постоянный диск и могут терять локальные файлы. Перед подтверждением Blueprint Render покажет стоимость — проверьте её и не подтверждайте платный запуск, если не согласны. Источники: https://render.com/docs/free и https://render.com/docs/disks.

## Важное ограничение текущего каталога
Исходный HTML каталога сохраняет добавленные модели в браузерном хранилище (или в среде Claude Artifact, если она доступна). Поэтому сам сайт уже открывается с Render по общей ссылке, но список загруженных моделей и их файлы пока не синхронизируются между разными устройствами и браузерами. Для общей базы каталога потребуется следующий этап: перенос метаданных и файлов моделей в серверную базу/объектное хранилище и замена локального слоя хранения в `index.html`.

## Поиск и скачивание моделей
На первом этапе бот пересылает точную ссылку клиента или формирует поисковые ссылки MakerWorld/Printables. Он не скачивает произвольные модели автоматически: для надёжного скачивания нужны поддерживаемые официальные API/прямые ссылки и проверка прав доступа. Не обходятся авторизация, CAPTCHA, платные ограничения или защита сайтов. Следующий этап — добавить интеграцию с конкретными API/разрешёнными источниками и отправку STL/3MF после проверки.

## Безопасность
- Никогда не помещайте токен Telegram в `index.html`, GitHub или сообщения.
- Если токен случайно утёк, перевыпустите его через BotFather.
- Не добавляйте `ADMIN_CHAT_ID` в публичный HTML.
